# SyncScore 🚀

> **Team Contribution & Project Management Platform**

SyncScore is a full-stack web application that helps teams manage tasks, track project activities, and monitor member contributions in one place.

## 🌟 Features

* 🔐 **Login & Authentication** – Secure user login with different roles.
* 📂 **Project Management** – Create projects, set deadlines, and manage team members.
* 📋 **Task Management** – Create, assign, and track tasks.
* 📊 **Project Tracking** – Monitor task progress, workload, inactive members, and deadlines.
* 📝 **Project Reports** – Generate project activity summaries.
* 🐙 **GitHub Integration** – Track repository commits and member contributions.

## 🛠️ Tech Stack

* **HTML** – Frontend structure
* **JavaScript** – Application logic
* **React.js** – Frontend development
* **Node.js** – Backend development
* **Express.js** – Server and API handling
* **SQL** – Database

## ⚙️ Setup

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend:

```text
http://localhost:5173
```

Backend:

```text
http://localhost:5000
```
